# 12 · 现场救援手册（嵌墙安卓标牌被 kiosk 锁死时怎么办）

> 适用机型：RK312x（RK3126 / RK3128）标牌 / 相框板，Android 4.4.4 (API 19)，无文件管理器。
> 典型故障：装了一个会锁屏的版本（如 LumaSign **v1.3.11**）后黑屏、无法退出、无法卸载。
>
> 本手册按「**代价从小到大**」排序。**先试 A，A 不行再 B，不要一上来就刷机。**

---

## 0. 先看清"黑屏"是哪一层（30 秒，决定后续所有判断）

| 现象 | 含义 | 走哪个方案 |
|---|---|---|
| 全黑底 + **极暗的灰字** | 应用自己的故障遮罩（`#6b7280`/16sp，低亮度下像没字）。v1.3.11 会显示「灵屏 LumaSign / 正在连接服务端…」或「无法连接服务端…将自动重试…」 | A / B / D |
| 全黑底 + **较亮的灰字**「灵屏 LumaSign / 正在恢复播放…」 | kiosk 守卫的应急悬浮窗 | A / B |
| **纯黑，一点字都没有，但屏幕背光亮** | 应用崩了或 WebView 没渲染 | A / B |
| 屏幕**完全没背光** | 不是软件问题：查 12V 电源 / 断线 | — |

> ⚠️ 手电筒照屏幕侧面看更容易分辨有没有暗字。

---

## A. 安全模式（**首选**，可逆、不丢数据）

**原理**：安全模式下 Android 会禁用所有装在 `/data` 的第三方应用。
LumaSign 的 `MainActivity`（它同时注册了 `category.HOME`）和 `KioskGuardService`（**每 2 秒把你拉回前台的那个**）都不会启动 →
**kiosk 锁自动失效**，系统回落到原生/厂商桌面 → 就能进设置清数据或卸载。

### 进法 1：电源菜单（Android 4.4 官方姿势）
1. 接上 **USB 键鼠**（板子的 USB-A `HOST` 口；2.4G 无线接收器也行）。
2. **长按电源键**调出电源菜单（关机 / 重启 / 飞行模式）。
   - 电源菜单是**系统级对话框，层级高于应用**，v1.3.11 的悬浮窗盖不住它，通常能操作。
3. **长按菜单里的「关机」那一项约 2 秒**，直到弹出「重启进入安全模式？」。
4. 确认 → 重启。
5. 进桌面后**左下角会显示「安全模式」**字样。

### 进法 2：开机按键（部分 ROM 支持）
1. 断电（拔 DC 12V）。
2. 插上 USB 键盘，**按住键盘的 `MENU` 键**（或 `音量-`）。
3. 上电，**一直按住**直到桌面出现，再松开。

### 进了安全模式之后（二选一）
- **外科手术式（推荐）**：设置 → 应用 → 全部 → **灵屏播放端** → **清除数据**（清掉存错的服务器地址）→ 再 **卸载**（如果按钮可用）。
  > 只清 LumaSign 的 `server_url`，**不动系统、不动 WiFi、不动厂商客户端**。
- **彻底式**：设置 → 备份和重置 → 恢复出厂设置。

> 清完数据后正常重启，LumaSign 的 `server_url` 为空 → 会自动走 **UDP 零配置发现** →
> 找到局域网里的管理端 → **屏幕自己就活了**（v1.3.15 起还会自愈）。

## B. Recovery 模式 `wipe data/factory reset`（**最稳**，能进就一定成）

`wipe data` 只擦 `/data`（应用与数据），**系统分区不动，不会变砖**。
代价：**所有应用数据被清**——如果 LumaSign 是普通安装的应用，**它会被一起卸载**；`server_url` 当然也没了。

1. **断电**（拔 12V DC）。
2. 找到板子上的 **`RECOVERY` / `REC` / `RESET` 按键或小孔**（有的板是标 `REC` 的 3 针排针，需要短接）。
   - 相框/标牌板常见位置：网口旁、USB 口旁、板子边缘。
3. **按住它不放** → 插上 12V **通电** → 保持按住 3–5 秒后松开。
4. 进入 **Rockchip Recovery** 菜单（黑底白字/彩字）。
5. 用 **USB 键盘的方向键 / Enter**（或板上按键：音量± 移动、电源 确认）选择：
   - `wipe data/factory reset` → 确认（选 `Yes -- delete all user data`）
   - 然后 `reboot system now`
6. 首次重启会较慢（要重建 `/data`），耐心等 1–3 分钟。

> **如果插着 USB 键盘却动不了菜单**：换用板上按键；或试试把键盘换到另一个 USB-A 口。
> **如果进不去 Recovery**：说明该板没有暴露 REC 键，走 D 或 E。

---

## C. 如果能进系统桌面（安全模式或别的办法）

**设置 → 备份和重置 → 恢复出厂设置 → 重置平板电脑 → 全部清除**

或者只做外科手术：**设置 → 应用 → 灵屏播放端 → 清除数据 → 卸载**

---

## D. USB adb 直卸（最快，前提是能连上）

1. 用一根**确定能传数据**的 micro-USB 线（**不要用只充电的线**）连接板子的 **micro-USB（OTG）口** 与电脑。
2. 听 Windows 是否"叮"一声、设备管理器是否多出设备。
3. 能看到设备后：
   ```bash
   adb devices -l
   adb uninstall com.lumasign.player
   ```
4. 卸干净后再装修复版（**v1.3.15 起地址不带 `http://` 也会自动补全**）：
   ```bash
   adb install -r LumaSign-android-v1.3.15-armeabi-v7a.apk
   ```

> 本机 adb 路径：`C:\Users\DMax\AppData\Local\Programs\lumasign\resources\app\desktop\adb\platform-tools\adb.exe`
> 管理端「设备开通」页的 `adbPath` 也已指向它。

### 💡 这批屏的固件是 `eng` + `test-keys`，对救援是大利好

实测固件身份：`rk312x-eng 4.4.4 KTU84Q eng.root.20200828.113332 test-keys`。
`eng`（工程版）+ `test-keys` 意味着：

- **`ro.adb.secure` 通常为 0 → adb 连接不需要在屏幕上点「允许 USB 调试」**
- **`ro.secure` 通常为 0 → `adb shell` 直接就是 root**
- 因此只要 **USB 能枚举**，救援几乎没有阻力：`adb uninstall com.lumasign.player` 一把过
- 实在不想卸载，也可以直接删掉存错地址的偏好文件：
  ```bash
  adb shell "su -c 'rm -f /data/data/com.lumasign.player/shared_prefs/luma_config.xml'"
  adb shell reboot
  ```

**反过来说：如果连设备描述符都拿不到（`adb devices` 空、设备管理器无新设备），那一定是"线/口"层面的物理问题，不是系统设置问题**——换一根确定能传数据的线再试。

## E. 厂商（触拓 / 零度 Ebanswers）远程卸载

**前提**：屏幕的厂商客户端仍在线（会与 E版服务器保持 **XMPP 长连接，TCP 5222**）。

**判断屏幕是否在线**：在 E版服务器那台机器上执行
```bash
netstat -ano | findstr :5222
```
有**外部 IP** 的 `ESTABLISHED` → 屏幕在线。

E版后台可用指令（见 `webedit.cd_task_type` 字典）：

| CODE_VALUE | 含义 |
|---|---|
| `UnApkInstall` | **远程卸载**（正是我们要的） |
| `ApkInstall` | 远程安装 |
| `com.ebanswers.plus.remote_recovery.receiver.UpdateTask` | 固件升级 |
| `RestartComputer` | 重启终端 |
| `Server` | 重新注册 |
| `CloseScreen` / `OpenScreen` | 远程关屏 / 开屏 |
| `ClearUpFiles` | 清理文件 |

**注意**：E版**没有"恢复出厂"遥控指令**，只能靠上面这些组合。
入口：`C:\DS\WebEdit\ApkAciton.aspx`（远程装/卸）、`AppManage.aspx`。
**本机（DESKTOP-2TH64T7）这台 E版 是 2026-08-03 新装的空库**（`eb_player` / `eb_playerex` / `eb_app_manage` 全为 0 行），
且 `:5222` 上只有本机自连 → **当前无法用它救**。若屏幕挂在**另一台** E版 上，去那台操作。

## F. 重刷固件（**最后手段，有变砖风险**）

⚠️ **警告**：进入 **MASKROM 模式后做"低级格式化"会连系统分区一起擦掉。**
**没有厂商原厂固件包（`update.img`）就绝对不要做这一步**——擦完没有固件可刷 = 真砖。
只有在「厂商给了固件 + Recovery 也进不去 + 这台屏不要了」时才考虑。

📖 **完整流程见 → [`13-重刷固件指南-RK312x.md`](./13-重刷固件指南-RK312x.md)**（工具、Loader/MaskROM 两种入口、
已知坑、通刷包风险警告、TTL 串口兜底）。

> **一个重要认知**：`RECOVERY` 键和刷机用的是**同一个按键**——
> 按住它**开机** → 进 Android Recovery（**不用固件**）；按住它**插 USB** → 进 Loader/MaskROM（**要固件**）。
> 所以**永远先试 Recovery `wipe data`**，它和刷机一样能回到出厂，但零风险。

## G. 救援成功后的收尾（别漏）

- [ ] 确认屏幕已能正常播放（管理端「终端管理」里能看到该终端，或「监看墙」有缩略图）
- [ ] 升级到 **v1.3.15 或更新**（该版本才修掉了填错地址锁死的坑）
- [ ] **重填服务器地址时用完整格式**：`http://192.168.2.97:7788`
       > v1.3.15 起不写 `http://` 也会自动补全；**v1.3.11–v1.3.14 不写就会锁死**
- [ ] 若做过恢复出厂：检查 WiFi 是否还在、厂商客户端是否要重新登录
- [ ] 若动了 `KioskGuardService` / Device Owner：`adb shell dpm remove-active-admin com.lumasign.player/.KioskAdminReceiver`（**该操作会清设备用户数据，先确认**）

## 附：这类事故的根因备忘（2026-09-30 定案）

LumaSign **v1.3.11** 的 `MainActivity`：

- `showConfigDialog()` **原样落盘**用户输入，`loadPlayer()` 直接拼 `server + "/player/?mode=term"`。
  填 `192.168.2.97:7788`（不带 `http://`）→ WebView 把 IP 当**协议名** → **URL 在本地即判非法、一次 TCP 都不发**
  → `onReceivedError` → 每 15s 重试**同一个坏 URL**。
- 锁死的四重原因：① 无 `onKeyDown`/`onTouchEvent`/手势 → **配置框一关再也打不开**；
  ② `onBackPressed()` 空实现；③ 清单里 `MainActivity` 注册了 `category.HOME`（**它自己就是桌面**）；
  ④ `KioskGuardService` 在 4.4 上每 2s 拉回。
- **已修于 v1.3.15**：地址规范化 + 遮罩亮字与三个救援按钮 + 连续 4 次失败后自动零配置发现自愈。

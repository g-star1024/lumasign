# 04 · 终端替换迁移指南（0 成本替换数字标牌 e 版）

目标：用 **灵屏 LumaSign** 的播放端顶替触拓 e 版的「液晶互动」播放端，并停用 e 版管理服务器，实现 0 成本替换。已在单局域网、1–50 台安卓终端场景下验证思路可行（用户侧设备已确认允许侧载第三方 APK）。

## 一、前提确认

| 项目 | 说明 |
| --- | --- |
| 网络 | 单一局域网，服务端 PC 与安卓终端同网段 |
| 设备 | 安卓广告机 / 电视盒，系统允许「未知来源」安装 |
| 服务端 | 一台常开 PC（Win/Mac 均可），运行 `node server/server.js` |
| 现状 | 终端已装「液晶互动」（e 版播放端），证明可侧载 APK |

## 二、迁移流程

### 步骤 1 · 部署服务端
1. 在服务端 PC 安装 Node.js 18+。
2. 拷贝 `lumasign/` 目录，运行 `启动-Windows.bat`（或 `启动-Mac.command`）。
3. 浏览器访问 `http://<服务端IP>:7788/`，用 `admin / admin123` 登录并立即改密。
4. 在「系统设置」中按需调整心跳间隔、离线判定、是否自动准入新终端。

### 步骤 2 · 安装 LumaSign 播放端（替换「液晶互动」）
1. 安卓终端开启「设置 → 安全 → 未知来源 / 允许安装未知应用」。
2. 通过 U 盘或局域网推送安装 **LumaSign 播放端 APK**（工程见任务 #7：`android/` 目录，Kotlin WebView 壳 + 本播放引擎）。
3. 不卸载「液晶互动」也可并存；验证无误后再卸载 e 版播放端。

### 步骤 3 · 自动注册入网
1. 打开 LumaSign 播放端，应用向 `7789` 广播 `LUMASIGN_DISCOVER`。
2. 服务端应答 HTTP 地址，播放端自动注册并拉取清单。
3. 管理端「终端管理」中出现新终端 → 点「控制 / 批准」完成准入（若开启自动准入则免审批）。

### 步骤 4 · 制作与下发
1. 「素材库」上传图片 / 视频 / 文档。
2. 「节目制作」从 12 套内置模板新建，或用编辑器拖排区域与条目（右侧实时预览 = 终端实际渲染）。
3. 「排期下发」绑定 节目 → 目标终端/分组/机构，选择播放方式（默认/周期/插播/独占）。
4. 终端按心跳周期拉取清单，命中时段的节目自动切换；断网时播放本地缓存，再降级到内置兜底页。

### 步骤 5 · 停用 e 版管理系统
- e 版管理服务器可关机；终端播放由 LumaSign 服务端接管。
- 保留 e 版「液晶互动」APK 直至 LumaSign 播放端连续运行稳定，再卸载。

## 三、回退预案
- 播放端 APK 支持 U 盘离线导入兜底节目，断网/服务端故障时不黑屏。
- 如需回退：重新打开「液晶互动」并接回 e 版服务器即可，互不影响。

## 四、Web 终端（联调 / 演示）
浏览器打开 `http://<服务端IP>:7788/player/index.html?mode=term`，即作为一台 Web 终端自动注册，可在「终端管理」中远程截图 / 刷新 / 重启，用于快速验证链路，无需安卓设备。

## 五、注意事项
- 多网卡环境：发现服务会按同网段优先回包，避免回错地址。
- 端口冲突：`7788`（HTTP）/ `7789`（UDP 发现）被占用时在「系统设置」或环境变量 `LUMASIGN_PORT` 调整。
- 数据备份：直接拷贝 `server/data/` 目录即可全量备份 / 迁移。

# 灵屏 LumaSign · 触拓(56iq) 兼容控制层 · 使用与对接文档

> 配套代码：`server/lib/siqian.js`（核心模块）、`server/api/siqian.js`（管理端 API）、`server/server.js`（接入）。
> 协议依据：`Downloads/触拓_协议深挖笔记.md`。
> 适用版本：v1.3.39+（本控制层为新增原型模块）。

## 1. 它解决什么

让**灵屏服务端**能够统一管控 **56iq / 触拓（液晶互动）** 播放端，两条路径：

| 路径 | 说明 | 适用场景 |
|---|---|---|
| **直连控制** | 灵屏用 `SiqianPlayerClient` 直接调已知 IP 的 56iq 播放端 OpenAPI | 现场已有 56iq 设备，IP 已知，不想改动其服务端指向 |
| **兼当 CMS** | 灵屏在 8888 端口实现 56iq OpenAPI，56iq 播放端把 `serverHost` 指过来即自动注册 | 希望 56iq 设备像灵屏终端一样入网、被统一下发 |

## 2. 启动与端口

- 主服务端口不变（默认 7788）。
- 56iq CMS 兼容层默认监听 **8888**（可被 `settings.siqianPort` 覆盖；`siqianEnabled=false` 可关闭）。
- 8888 被占用时**自动跳过**，不影响主服务；日志打印 `[siqian] 8888 端口占用…`。

## 3. 让 56iq 播放端接入灵屏

### 方式 A：局域网自动发现（推荐批量）
1. 灵屏管理端调用 `POST /api/admin/siqian/discover` → 向组播 `239.255.255.255:51008` 广播 `registerServerInfo`。
2. 56iq 播放端收到后，自动 `GET http://<灵屏IP>:8888/api/server?ip=<自身IP>&name=<名称>` 完成注册。
3. 注册设备出现在 `GET /api/admin/siqian/devices`。

> 注：56iq 原生广播包格式未在 APK 中公开（DEX 仅见标签名），本层用 JSON 行广播并透传 `serverInfo`。若现场不生效，改用方式 B 手动指向。

### 方式 B：播放端手动指向（最稳）
- 在 56iq 播放端的注册向导里，把「服务器地址」填成**灵屏服务端 IP**（或域名），端口留空（默认 8888）。
- 或在 `ebanswers.properties` 写 `webHost=<灵屏IP>`，重启播放端即注册。

### 方式 C：灵屏侧手动登记已知 IP
- `POST /api/admin/siqian/register` `{ "ip": "192.168.2.153", "name": "触拓A" }`。

## 4. 管理端 API（前缀 `/api/admin/siqian`）

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/devices` | terminal:view | 已登记 56iq 设备列表 + CMS 状态 |
| POST | `/discover` | terminal:manage | 触发局域网发现广播 |
| GET | `/:id` | terminal:view | 单设备详情 |
| GET | `/:id/now` | terminal:view | 直连查询当前播放 |
| POST | `/:id/play` | schedule:publish | 直连播放 `{programId, scene?}` |
| POST | `/:id/volume` | terminal:upgrade | 直连设音量 `{volume:0-100}` |
| POST | `/:id/message` | schedule:publish | 直连插播 `{msg}` |
| POST | `/register` | terminal:manage | 手动登记设备 |
| DELETE | `/:id` | terminal:manage | 删除登记 |

## 5. 兼容层自身 OpenAPI（8888，供 56iq 播放端调用）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/server?ip=&name=` | 播放端注册上报 |
| GET | `/api/program/programs/list` | 返回灵屏映射的当前节目 |
| GET | `/api/program/programs/nowlist` | 当前播放 |
| GET | `/api/action/play/<id>/<scene>` | 播放指令 |
| GET | `/api/action/volume/<0-100>` | 音量 |
| GET | `/api/action/InsertMessage?msg=` | 插播 |
| POST | `/TransferFeedback.aspx` | 播放端反馈（playlog/状态）落库 |
| GET | `/UpdatePlayer/EAutoUpdate.xml` | OTA 升级清单 |
| GET | `/api.html` | 内置 OpenAPI 文档页（现场验证用） |

## 6. 节目映射

灵屏把「终端 + 排期」映射成 56iq 的 `programs/list` 响应（`ProjectId/ProjectName/Scene`）。原型阶段：
- 若 `terminals` 中存在同 IP 的灵屏终端 → 以其 `name` 作为 `ProjectName`；
- 否则返回默认占位节目。
后续可扩展为：把灵屏 layout 渲染成 56iq 的 `resource.xml` + `TaskList.config` 真实下发（见全兼容升级方案）。

## 7. 验证

```bash
# 启服务后，本机模拟一个 56iq 播放端向灵屏 CMS 注册并查询
curl "http://localhost:8888/api/server?ip=10.0.0.9&name=触拓A"
curl "http://localhost:8888/api/program/programs/list?ip=10.0.0.9"
curl "http://localhost:8888/api/action/volume/50?ip=10.0.0.9"
curl "http://localhost:8888/api.html"
```

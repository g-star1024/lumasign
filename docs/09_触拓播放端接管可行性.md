# 触拓 E 版播放端接管可行性分析

> 来源：`2，E版安卓播放端注册.pdf`、`4，E版节目制作与发布.pdf`（用户提供的官方说明文档）
> 日期：2026-08-05

## 一、触拓播放端关键信息（来自官方文档）

**播放端软件名**：「液晶互动」（安装包名 `ebplayer-4.x`，如 ebplayer-4.3.2）

**注册方式**（两种）：
- **方法一（后台搜索）**：服务器后台「终端管理 - 终端监控 - 搜索终端」，按 IP 搜索自动注册（仅同局域网）
- **方法二（终端注册）**：设备端 Settings / 企业登录 → **输入 URL(服务器 IP 地址) + 终端名称** → 注册

**发布流程**（来自节目制作文档）：
- 制作：素材上传 → 节目制作（命名+分辨率+场景）→ 保存
- 发布三种入口：直接发布 / 节目管理-管理-发布 / 节目管理-发布-新建发布
- 流程统一为：**发布 → 选择终端 → 确定发布 → 发布成功**
- 发布后可在「**节目管理 - 下载管理**」查看**下载进度**

## 二、对「接管」问题的判断

### ✅ 已确认：服务器地址可配置

方法二明确终端需「输入 URL(服务器 IP 地址)」注册 —— 说明触拓播放端连接的服务器**不是写死的，是可配的**。这是接管可能性的前提条件。

### ⚠️ 关键疑点：播放模式是「下载」还是「远程加载」

文档中「**下载管理 / 下载进度**」措辞强烈暗示：触拓发布节目时，是把节目文件**下载到终端本地**再播放，而非让终端实时加载远程网页（WebView 拉取模式）。

### 结论矩阵

| 场景 | 能否接管 | 说明 |
|---|---|---|
| 触拓是「WebView 加载服务器页面 + 拉取节目 JSON」 | ✅ 可接管 | 服务端实现触拓协议兼容层，设备零安装即可连灵屏 |
| 触拓是「下载节目包到本地 + 私有格式原生渲染」 | ❌ 不可接管 | 节目格式私有，无法让它的播放器加载我们的 `/player/` 页面 |

**当前基于文档的判断**：因存在「下载管理」概念，**偏向于不可直接接管**（更接近下载私有格式模式）。但文档未给出接口细节，无法 100% 下定论。

## 三、推荐的务实路线

1. **短期（稳）**：继续用灵屏自研 APK（`android/` 工程已就绪），通过「设备开通」远程装机替换触拓 app。
2. **探索接管（可选）**：找一台装了触拓的设备，用抓包工具（Charles / adb + tcpdump / Wireshark）捕获其：
   - 注册请求（URL、参数、协议）
   - 心跳/轮询请求
   - 节目发布后的「下载」请求（下载的是什么？URL 格式？返回格式？）
3. 若确认为 WebView 拉取模式 → 在灵屏服务端加「触拓兼容 API 层」（注册/心跳/发布/播放页），实现**零安装接管**。
4. 若确认为下载私有格式 → 放弃接管，维持自研 APK 替换路线。

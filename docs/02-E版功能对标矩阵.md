## C. LumaSign 相对 E 版的增量能力

以下是 E 版**没有**、我们额外提供的：

| 增量能力 | 价值 |
|---|---|
| **macOS 级视觉设计 + 三态主题（明/暗/跟随系统）** | 行业内唯一，直接拉开观感差距 |
| **Mac 原生支持** | E 版完全做不到 |
| **零依赖免构建部署** | 拷贝即用，比 IIS 一键安装还省一步 |
| **播放证明报表（Proof of Play）** | 某素材在哪台屏播了多少次/多少秒，可用于广告结算 |
| **室内平面图定位**（替代在线地图） | 局域网无外网时依然可视化，且更贴合室内场景 |
| **Webhook 告警**（企业微信/钉钉/飞书） | E 版只有邮件 |
| **素材 SHA-256 去重** | 同一素材重复上传只存一份，省存储省带宽 |
| **编辑器与播放端同引擎** | 彻底消除「编辑器好好的，屏上变形」 |
| **终端准入审核** | 防止未授权设备蹭网接入 |
| **完整 OpenAPI 文档** | 二次开发不再求厂商 |
| **数据即文件，备份=拷贝文件夹** | 无需 DBA，运维零门槛 |
